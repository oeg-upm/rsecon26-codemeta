About the workshop

From fragmented metadata to interoperable research software descriptions

Research software metadata is often fragmented across formats, making software harder to discover, cite and reuse. CodeMeta provides a standardized, machine-readable vocabulary based on JSON-LD and Schema.org that can act as a metadata exchange layer across software repositories and tools.

In this workshop, participants will combine short introductions, demonstrations and hands-on activities. You will generate CodeMeta metadata for research software, identify common metadata problems and experiment with structured mappings between other metadata schemas and CodeMeta.

You will learn to

  • Understand the CodeMeta schema and its core concepts.
  • Generate codemeta.json using automated tools.
  • Improve software metadata by detecting common pitfalls.
  • Map metadata from other schemas into CodeMeta.
  • Assess ambiguous mappings and possible information loss.
  • Explore LLM-assisted approaches for difficult mapping cases.

Exercise 2 · 40 min

Map your metadata schema to CodeMeta

Select a schema, examine 8–12 representative properties and create a justified crosswalk to CodeMeta.

  • Compare semantics, not just property names.
  • Classify straightforward and difficult mappings.
  • Record transformations and information loss.
  • Compare selected decisions with an LLM recommendation.

Before the workshop

What to bring

Required

A laptop with Internet access.

Recommended

A GitHub account and a research software repository you can use during the exercises.

Optional

A metadata schema that you would like to map into CodeMeta during the second exercise.

No prior knowledge of CodeMeta or metadata standards is required. The workshop is designed to be accessible to beginners while also including advanced mapping and LLM-assisted topics.
